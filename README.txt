WEB LAB 123

Sitio HTML5 listo para publicar.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea un repositorio público nuevo en GitHub.
2. Sube todo el contenido de esta carpeta, dejando index.html en la raíz.
3. Abre Settings > Pages.
4. En Build and deployment elige Deploy from a branch.
5. Selecciona la rama main y la carpeta /root.
6. GitHub mostrará la dirección pública de tu sitio.

PUBLICAR CON CLOUDFLARE PAGES
1. Crea un proyecto de Pages.
2. Conecta tu repositorio o usa el método de carga disponible en tu cuenta.
3. Publica la carpeta que contiene index.html.
4. El sitio recibirá una dirección tipo nombre.pages.dev.

JUEGOS
- Juegos propios: crea una carpeta dentro de games/ y enlaza su index.html.
- Juegos externos: solo funcionarán dentro del iframe si el sitio externo permite embedding.

Este proyecto no incluye proxy, cloaking ni mecanismos para saltarse bloqueos de red.
