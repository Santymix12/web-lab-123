WEB LAB 123

Sitio HTML5 listo para publicar.

JUEGOS INCLUIDOS
- Meteor Dodge: juego original del proyecto.
- 2048: https://github.com/gabrielecirulli/2048 - MIT.
- Hextris: https://github.com/Hextris/hextris - GPLv3.
- Snake: https://github.com/vis-a11y/Snake-Game - MIT.
- Asteroids HTML5: https://github.com/7affer/asteroids-html5 - MIT.
- Breakout: https://github.com/akshatjain02/Breakout - MIT.

Los juegos externos se cargan desde sus demos públicas dentro de un iframe. Si el propietario cambia su configuración y deja de permitir embedding, ese juego podría dejar de cargar dentro del reproductor.

PUBLICAR GRATIS CON GITHUB PAGES
1. Abre Settings > Pages.
2. En Build and deployment elige Deploy from a branch.
3. Selecciona main y /root.
4. Guarda los cambios.

JUEGOS NUEVOS
- Juegos propios: crea una carpeta dentro de games/ y enlaza su index.html.
- Juegos open source externos: agrega una tarjeta con su URL pública, respetando su licencia.

Este proyecto no incluye proxy, cloaking ni mecanismos para saltarse bloqueos de red.
